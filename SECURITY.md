# Security Policy

## Reporting a Security Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Security-related reports should be submitted through the official BOS Scripts support or security channel.

## What to Include

Please provide:

- A clear description of the vulnerability.
- The affected resource.
- The affected version.
- Steps to reproduce the issue.
- Relevant logs or technical information.
- Potential impact.

Do not publicly disclose the vulnerability before it has been reviewed.

## Supported Versions

Security fixes are primarily provided for actively maintained versions.

Older or unsupported versions may not receive security updates.

## Responsible Disclosure

BOS Scripts follows responsible disclosure practices.

We ask security researchers and users to allow reasonable time for investigation and remediation before publicly disclosing a vulnerability.
