# BOS Scripts Support

## Getting Help

For support with BOS Scripts resources, please use the official BOS Scripts support channels.

## Before Requesting Support

Please check:

- The README.md
- Installation instructions
- Configuration documentation
- Requirements
- Changelog
- Known issues

## Bug Reports

Confirmed software bugs should be reported through GitHub Issues.

Please provide:

- Resource name
- Version
- Framework
- Dependencies
- Description of the issue
- Steps to reproduce
- Relevant client/server console errors
- Configuration relevant to the issue

## Security Issues

Security vulnerabilities must not be reported through public GitHub Issues.

See `SECURITY.md`.

## Community Support

General questions and community discussions should take place through the official BOS Scripts community channels.
